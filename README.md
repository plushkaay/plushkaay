# Привет! 👋

Я развиваюсь в направлении **аналитики данных и продуктовой аналитики**. Работаю с данными: от подготовки и исследовательского анализа до проверки гипотез, оценки A/B-тестов и визуализации бизнес-показателей.

### Навыки и инструменты

- **Python:** pandas, NumPy, Matplotlib, Seaborn, SciPy, statsmodels
- **SQL:** PostgreSQL, JOIN, CTE, агрегирование, аналитические витрины
- **Аналитика:** EDA, очистка данных, статистические гипотезы, A/B-тестирование, продуктовые и бизнес-метрики
- **Визуализация:** Yandex DataLens, Jupyter Notebook
